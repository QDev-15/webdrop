Kiểm tra yêu cầu hosting

Website hỗ trợ cả hosting Linux (Apache) và hosting Windows (IIS). Đảm bảo đủ các yêu cầu bên dưới trước khi upload.

Yêu cầuMô tảCách kiểm tra
PHP 8.0+ Ngôn ngữ chạy backend Trong cPanel/Plesk → PHP Version / PHP Settings
SQLite (pdo_sqlite) Database mặc định (bắt buộc) Hỏi hosting: "Có hỗ trợ pdo_sqlite không?"
Quyền ghi thư mục PHP cần ghi file .db và ảnh upload Thường được cấp sẵn — kiểm tra nếu có lỗi
URL Rewrite Để routing hoạt động đúng Linux: mod_rewrite · Windows: IIS URL Rewrite (có sẵn)
Hosting nào dùng được? Linux: AZDIGI, Mắt Bão, Nhân Hòa, BKNS, Hostinger… — hầu hết đều OK.
Windows: PA Vietnam, hosting có Plesk + IIS + PHP — dùng được bình thường.
2

Giải nén file nhận được

Sau khi mua hàng, bạn tải về 1 file ZIP duy nhất chứa toàn bộ website.

📦 deploy.zip ← file bạn nhận được
├── index.html       ← Website hiển thị cho khách
├── assets/          ← JS, CSS của website
├── .htaccess        ← Dành cho hosting Linux/Apache
├── web.config       ← Dành cho hosting Windows/IIS
├── admin/           ← Trang quản trị
│   ├── index.html
│   └── assets/
└── api/             ← PHP backend (dùng chung)
    ├── index.php
    ├── config.php   ← File bạn cần chỉnh
    ├── database/    ← SQLite tự tạo ở đây
    └── uploads/     ← Ảnh upload
1
Giải nén deploy.zip ra thư mục trên máy tính

Chuột phải vào deploy.zip → Giải nén tại đây (Extract Here)

2
Tiếp tục bước 3 — chỉnh config.php trước khi upload

Không upload ngay — cần điền thông tin website trước

3

Cấu hình file config.php

Chỉ có 1 file config duy nhất tại api/config.php. Mở bằng Notepad hoặc bất kỳ text editor nào.

Chỉ cần sửa 3 dòng sau:

// SỬA: thay bằng địa chỉ website của bạn (không có / ở cuối)
define('APP_URL', 'https://TENMIEN.COM');

// Đổi thành 'production' khi dùng thật
define('APP_ENV', 'production');

// SỬA: tạo chuỗi bất kỳ 32 ký tự để bảo mật
define('APP_KEY', 'ĐỔI-THÀNH-CHUỖI-32-KÝ-TỰ');
DòngGiải thíchVí dụ
APP_URL Địa chỉ website, không có dấu / ở cuối https://tiembanh.com
APP_ENV Môi trường — khi dùng thật đặt production production
APP_KEY Khóa bảo mật session — phải đổi ngay 32 ký tự bất kỳ
Tạo APP_KEY ngẫu nhiên Truy cập passwordsgenerator.net → chọn độ dài 32 → copy dán vào.
4

Upload lên hosting

Upload toàn bộ nội dung bên trong thư mục deploy lên thư mục gốc của hosting (public_html hoặc httpdocs).

Linux hosting / cPanel Apache
Windows hosting / Plesk IIS
1
Đăng nhập vào hosting panel

cPanel: tenmien.com/cpanel  ·  Plesk: link do nhà cung cấp gửi

2
Mở File Manager

cPanel: biểu tượng File Manager  ·  Plesk: nút Files ở sidebar trái

3
Vào thư mục gốc của hosting

cPanel: public_html/  ·  Plesk: httpdocs/

4
Upload toàn bộ nội dung thư mục deploy lên đây

Chọn tất cả file và thư mục bên trong deploy/ → kéo thả hoặc dùng nút Upload.
Lưu ý: upload nội dung bên trong, không phải upload cả thư mục deploy.

Cấu trúc sau khi upload đúng sẽ như sau:
public_html/ (hoặc httpdocs/)
├── index.html
├── assets/
├── .htaccess       ← Linux hosting dùng cái này
├── web.config      ← Windows hosting dùng cái này
├── admin/
└── api/
Lưu ý nếu hosting đã có website cũ Backup dữ liệu cũ trước khi upload đè. Đặc biệt cẩn thận với thư mục api/database/ nếu đã có data thật.
5

Trỏ tên miền (nếu cần)

Nếu hosting mới chưa có tên miền trỏ vào, làm bước này. Nếu đã có rồi, bỏ qua.

1
Tìm địa chỉ IP của hosting

cPanel: Server Information → Shared IP Address
Plesk: Websites & Domains → xem IP bên cạnh domain

2
Truy cập nơi bạn mua tên miền

Nhân Hòa, GoDaddy, Namecheap, VNPT…

3
Sửa bản ghi A record

Tìm bản ghi A → đổi giá trị thành IP hosting → Save

4
Chờ DNS cập nhật

Thường 5–30 phút, tối đa 24 giờ. Kiểm tra tại whatsmydns.net

6

Kiểm tra website hoạt động

Database SQLite sẽ tự động tạo và seed dữ liệu mặc định ngay lần đầu trình duyệt gọi API — không cần thao tác thủ công.

1
Mở trình duyệt, vào địa chỉ website

Ví dụ: https://tiembanh.com — website chính hiện ra

2
Vào trang admin

Thêm /admin vào cuối: https://tiembanh.com/admin

3
Đăng nhập lần đầu bằng tài khoản mặc định
  • Email: admin@example.com
  • Mật khẩu: admin@123
Thấy trang đăng nhập admin → cài đặt thành công! Database đã tự tạo xong. Tiếp tục bước 7 để đổi mật khẩu.
7

Đổi mật khẩu admin ngay!

Bảo mật — Làm ngay sau khi đăng nhập lần đầu Mật khẩu mặc định admin@123 là công khai. Đổi ngay để tránh bị xâm nhập.
1
Sau khi đăng nhập, vào mục Cài đặt

Nhấn biểu tượng ⚙ Cài đặt ở sidebar trái

2
Đổi mật khẩu và cập nhật thông tin website

Tên website, mô tả, email liên hệ, số điện thoại, địa chỉ…

8

Xử lý lỗi thường gặp

Lỗi gặp phảiNguyên nhânCách sửa
Trang trắng hoàn toàn Lỗi cú pháp config.php Mở lại config.php — kiểm tra dấu nháy đủ cặp, không thiếu dấu chấm phẩy
Lỗi 404 khi vào /admin hoặc refresh trang File routing chưa hoạt động Linux: liên hệ hosting bật mod_rewrite · Windows: đảm bảo web.config đã upload
Admin báo lỗi kết nối API APP_URL sai trong config.php Kiểm tra api/config.php — APP_URL đúng domain, không có dấu / cuối
Upload ảnh không thành công Thư mục uploads thiếu quyền ghi File Manager → chuột phải api/uploads/ → Permissions → đặt 755
Không đăng nhập được — sai mật khẩu Database chưa seed hoặc APP_URL sai Xóa file api/database/app.db rồi vào lại trang — DB sẽ tạo lại
Lỗi 500 Internal Server Error PHP không đọc được file hoặc thiếu extension Kiểm tra PHP version ≥ 8.0 và pdo_sqlite đã bật trong hosting panel
Vẫn còn lỗi? Liên hệ hỗ trợ webdrop.vn qua Zalo hoặc email với mô tả lỗi + URL website. Phản hồi trong 24 giờ làm việc.

Checklist cài đặt

  • ☐Mở api/config.php — điền APP_URL đúng domain
  • ☐Đổi APP_KEY thành chuỗi ngẫu nhiên 32 ký tự
  • ☐Upload toàn bộ nội dung deploy/ lên public_html (hoặc httpdocs)
  • ☐Trỏ tên miền về hosting (nếu cần)
  • ☐Vào website và /admin — kiểm tra hoạt động
  • ☐Đăng nhập admin → đổi mật khẩu và điền thông tin website
