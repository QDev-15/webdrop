# Nhà Hàng Chay Organic — Website Deploy

Website đầy đủ cho nhà hàng chay organic: React SPA frontend + React SPA admin + PHP backend + SQLite.

---

## Cấu trúc sau khi build

```
deploy/
├── index.html            ← Trang chủ React SPA
├── assets/               ← JS/CSS/assets frontend
├── .htaccess             ← Routing Apache/Linux
├── web.config            ← Routing IIS/Windows
├── admin/                ← Admin panel React SPA
│   ├── index.html
│   └── assets/
└── api/                  ← PHP backend
    ├── config.php        ← CẦN SỬA sau khi upload
    ├── schema.sql
    ├── index.php
    ├── database/         ← SQLite DB (tạo tự động)
    └── uploads/          ← Ảnh upload
```

## Hướng dẫn Build

### Yêu cầu
- Node.js 18+ với npm

### Bước 1 — Build
```bash
# Windows
build.bat

# Linux/Mac
bash build.sh

# Hoặc trực tiếp
node build.mjs
```

Script sẽ:
1. Tự động cài `npm install` nếu thiếu `node_modules`
2. Build React (website + admin) thành static files
3. Tạo thư mục `deploy/` với toàn bộ cấu trúc
4. Inject `APP_KEY` ngẫu nhiên vào `config.php`

## Hướng dẫn Deploy lên Hosting

### Bước 1 — Upload
Upload **toàn bộ nội dung** trong thư mục `deploy/` lên `public_html/` của hosting.

```
public_html/
├── index.html
├── assets/
├── admin/
├── api/
├── .htaccess   (hoặc web.config nếu IIS)
└── ...
```

### Bước 2 — Cấu hình (BẮT BUỘC)
Mở file `api/config.php` và sửa:

```php
// Sửa APP_URL thành URL thực của website (không có / cuối)
define('APP_URL', 'https://ten-website.vn');
```

`APP_KEY` đã được tạo tự động khi build — không cần sửa.

### Bước 3 — Phân quyền thư mục (nếu cần)
```bash
chmod 755 api/database/
chmod 755 api/uploads/
```

### Bước 4 — Kiểm tra health
Truy cập: `https://ten-website.vn/api/health`

Kết quả JSON phải có:
- `"pdo_sqlite": true` — nếu false: hosting không hỗ trợ SQLite
- `"db_dir": "writable"` — nếu not writable: `chmod 755 api/database/`
- `"schema_sql": "found"` — nếu MISSING: upload lại `api/schema.sql`

### Bước 5 — Đăng nhập admin
Truy cập: `https://ten-website.vn/admin`

```
Email:    sysadmin@admin.com
Mật khẩu: 123456
```

**Đổi mật khẩu ngay sau khi đăng nhập lần đầu!**

Vào menu Tài khoản (icon user dưới sidebar) → đổi mật khẩu.

## Troubleshooting

| Lỗi | Nguyên nhân | Giải pháp |
|---|---|---|
| 404 trang | .htaccess không hoạt động | Enable mod_rewrite hoặc dùng web.config |
| API 500 | schema.sql thiếu | Kiểm tra `/api/health` → schema_sql |
| DB not writable | Quyền thư mục | `chmod 755 api/database/` |
| Admin blank | Assets path sai | Kiểm tra admin/index.html có load assets |
| 401 Unauthorized | Session không lưu | Kiểm tra `api/database/sessions/` có writable |
