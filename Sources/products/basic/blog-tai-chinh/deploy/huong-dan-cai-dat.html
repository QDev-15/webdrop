Đưa website của bạn lên hosting

Hướng dẫn từng bước để cài đặt gói website (React + PHP + SQLite) sau khi tải về — không cần biết lập trình.

iTrong gói tải về có gì?
Website của bạn gồm 2 phần: trang web chính (khách truy cập) và trang quản trị /admin (bạn quản lý nội dung, đơn hàng...). Cả 2 đã được build sẵn — bạn chỉ cần upload lên hosting, không cần cài Node.js hay chạy lệnh gì.
thu-muc-giai-nen/ ├── index.html, assets/ ← trang web chính ├── web.config, .htaccess ← định tuyến (IIS / Apache) ├── favicon.ico ├── admin/ ← trang quản trị └── api/ ← xử lý dữ liệu (PHP + SQLite) ├── config.php ← chỉ cần sửa 1 dòng ở Bước 3 ├── database/ ← nơi lưu dữ liệu, tự tạo lần đầu chạy └── check-hash.php ← xóa file này sau khi cài xong (Bước 6)
1Yêu cầu hosting
  • Hosting hỗ trợ PHP 8.1 trở lên, có bật extension pdo_sqlite (hầu hết hosting cPanel/Plesk phổ biến ở Việt Nam đều có sẵn — nếu không chắc, hỏi bộ phận hỗ trợ nhà cung cấp hosting).
  • Hỗ trợ .htaccess (nếu hosting chạy Apache/LiteSpeed) hoặc web.config (nếu hosting chạy Windows/IIS) — gói tải về đã có sẵn cả 2 file, không cần tự tạo.
  • Có quyền ghi (write) vào thư mục — cần thiết để hệ thống tự tạo database và lưu ảnh upload.
2Giải nén và Upload lên hosting

2.1 Giải nén file .zip đã tải về ra 1 thư mục trên máy tính.

2.2 Đăng nhập cPanel (hoặc trình quản lý file của hosting) → mở File Manager → vào thư mục public_html (đây là thư mục gốc website).

2.3 Upload toàn bộ nội dung bên trong thư mục vừa giải nén vào public_html — lưu ý upload đúng các file/thư mục con (index.html, assets/, admin/, api/...), không upload cả thư mục cha bọc ngoài.

Mẹo: nếu hosting hỗ trợ upload file .zip rồi giải nén trực tiếp trên server (đa số cPanel đều có tính năng này) sẽ nhanh hơn nhiều so với upload từng file qua FTP.
3Cấu hình địa chỉ website

Mở file api/config.php bằng công cụ chỉnh sửa file trong cPanel (hoặc tải về sửa bằng Notepad rồi upload lại), tìm dòng:

define('APP_URL', 'http://localhost:8081');

Sửa thành đúng domain thật của website (không có dấu / ở cuối), ví dụ:

define('APP_URL', 'https://tenmiencuaban.vn');

APP_KEY đã được tự sinh ngẫu nhiên sẵn — không cần sửa dòng này.

4Kiểm tra website đã chạy chưa

Mở trình duyệt, truy cập: https://tenmiencuaban.vn/api/health

Nếu thấy dòng JSON có "status":"ok" — website đã sẵn sàng. Dữ liệu mẫu (danh mục, sản phẩm/bài viết mẫu...) sẽ tự động được tạo ngay lần truy cập đầu tiên, không cần thao tác gì thêm.

Nếu thấy báo lỗi liên quan "not writable" — xem mục "Xử lý sự cố" bên dưới.
5Đăng nhập trang quản trị

Truy cập: https://tenmiencuaban.vn/admin

Tài khoản mặc định:

  • Email: sysadmin@admin.com
  • Mật khẩu: 123456
Bắt buộc: đổi mật khẩu ngay sau lần đăng nhập đầu tiên — vào menu Hồ sơ trong trang quản trị.
6Hoàn tất — dọn dẹp bảo mật

Xóa file api/check-hash.php khỏi server sau khi đã cài đặt xong và kiểm tra hoạt động ổn định — đây là file debug chỉ dùng trong quá trình phát triển, không cần thiết khi website đã chạy thật và nên được gỡ bỏ để tránh lộ thông tin không cần thiết.

✓ Vậy là xong! Website đã sẵn sàng để sử dụng và giới thiệu tới khách hàng.
?Xử lý sự cố thường gặp

Thư mục api/database/ và api/uploads/ cần có quyền ghi. Trong File Manager của cPanel, click chuột phải vào 2 thư mục này → Permissions (hoặc CHMOD) → đặt thành 755. Nếu vẫn lỗi, thử 775.

Kiểm tra hosting đã đọc đúng file định tuyến chưa: Apache/LiteSpeed dùng .htaccess, Windows/IIS dùng web.config — cả 2 đã có sẵn trong gói tải về, đừng xóa nhầm. Một số hosting mặc định tắt .htaccess (cần bật AllowOverride All hoặc liên hệ nhà cung cấp hosting để bật hỗ trợ).

Thường do upload thiếu file hoặc sai cấu trúc thư mục — kiểm tra lại thư mục assets/ đã upload đầy đủ cùng cấp với index.html chưa (xem lại sơ đồ thư mục ở đầu trang). Mở Console trình duyệt (F12) để xem lỗi cụ thể nếu cần hỗ trợ thêm.

Kiểm tra quyền ghi (permissions) của thư mục api/uploads/ — làm tương tự hướng dẫn CHMOD ở mục đầu tiên.

Vào trang quản trị → Cài đặt → tab Thanh toán để bật/tắt hình thức thanh toán (COD, chuyển khoản QR...) và điền thông tin tài khoản ngân hàng. Mục này chỉ áp dụng với các website có bán hàng.

Đây là thay đổi kỹ thuật cần hỗ trợ trực tiếp — liên hệ theo thông tin bên dưới để được hướng dẫn.
