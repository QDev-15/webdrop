## Deploy lên Hosting

### Bước 1 — Upload files
Upload toàn bộ nội dung trong thư mục `deploy/` lên `public_html/` của hosting.

Cấu trúc sau khi upload:
```
public_html/
├── index.html          ← website trang chủ
├── assets/             ← JS, CSS của website
├── .htaccess           ← routing Apache
├── web.config          ← routing IIS
├── admin/              ← trang quản trị
│   ├── index.html
│   └── assets/
└── api/                ← PHP backend + database
    ├── index.php
    ├── config.php      ← CẦN SỬA APP_URL
    ├── schema.sql
    ├── database/       ← SQLite database (tự tạo lần đầu)
    └── uploads/        ← ảnh upload
```

### Bước 2 — Cấu hình (BẮT BUỘC)
Mở file `api/config.php` và sửa dòng sau:

```php
define('APP_URL', 'https://yourportfolio.vn');  // Sửa thành URL thực của bạn
```

Lưu ý:
- Không có dấu `/` ở cuối URL
- Phải là HTTPS nếu hosting có SSL

### Bước 3 — Kiểm tra hoạt động
Truy cập URL sau để kiểm tra:

```
https://yourportfolio.vn/api/health
```

Kết quả JSON phải hiển thị:
```json
{
  "status": "ok",
  "pdo_sqlite": true,
  "db_dir": "writable",
  "schema_sql": "found"
}
```

**Nếu có vấn đề:**
- `"pdo_sqlite": false` → Hosting không hỗ trợ SQLite, cần đổi sang MySQL (xem phần dưới)
- `"db_dir": "not writable"` → Chạy: `chmod 755 api/database/` qua SSH hoặc File Manager
- `"schema_sql": "MISSING"` → Upload lại file `api/schema.sql`

### Bước 4 — Phân quyền thư mục (nếu cần)
```bash
chmod 755 api/database/
chmod 755 api/uploads/
```

### Bước 5 — Đăng nhập admin
Truy cập: `https://yourportfolio.vn/admin`

```
Email:    sysadmin@admin.com
Mật khẩu: 123456
```

**Quan trọng:** Đổi mật khẩu ngay sau khi đăng nhập lần đầu (vào Tài khoản của tôi).

## Cấu hình nâng cao

### Sử dụng MySQL thay vì SQLite

Mở `api/config.php` và sửa:
```php
define('DB_TYPE', 'mysql');    // Đổi từ 'sqlite' thành 'mysql'
define('DB_HOST', 'localhost');
define('DB_NAME', 'ten_database');
define('DB_USER', 'ten_user');
define('DB_PASS', 'mat_khau');
```

### Cấu hình Cloudinary (lưu ảnh trên cloud)
Vào Admin > Cài đặt > Cloudinary và điền thông tin từ cloudinary.com

### Cấu hình SMTP (gửi email thông báo)
Vào Admin > Cài đặt > SMTP và điền thông tin SMTP.

Ví dụ Gmail:
- Host: `smtp.gmail.com`
- Port: `587`
- User: địa chỉ Gmail của bạn
- Pass: App Password (không phải mật khẩu Gmail thường)

### Cấu hình Unsplash (tìm ảnh miễn phí trong admin)
Vào Admin > Cài đặt > Tích hợp và điền Unsplash Access Key.
Đăng ký miễn phí tại: https://unsplash.com/developers
